# v2.30

## Improved View-only Mode

You don't need a VR headset to explore Open Brush sketches. We always had a basic [View-only mode](../user-guide/monoscopic-mode.md) but in this release we've improved the experience. It now has a thumbnail grid for browsing local and curated Icosa sketches, improved loading and navigation, and touch controls for mobile devices.

## Create Camera Paths by Flying

You can now create a [camera path](../user-guide/exporting-videos/camera-paths-tool.md) by recording a flight through your sketch. Start recording from the Camera Paths panel, use the Fly tool to move along the route you want, then stop recording to turn that movement into an editable camera path.

This is a more direct way to block out a camera move than placing every anchor point by hand. You can still adjust the resulting path, direction, speed and field of view before rendering it.

## 8K Panorama Support

Offline ODS panorama rendering can now produce images up to 8,000 pixels wide. The existing 4,096-pixel default is unchanged, but advanced users can request a larger output with the `Video.OfflineResolution` setting in `Open Brush.cfg`.

Higher resolutions require more time and memory, so choose a size appropriate for your computer and final output. See the [360° / ODS video workflow](../user-guide/exporting-videos/360-ods-video-workflow.md) for the rest of the rendering process.

## Passthrough in Multiplayer

[Multiplayer rooms](../user-guide/multiplayer.md#passthrough-rooms) can now use passthrough environments. This lets several people paint together while each person sees their own real-world surroundings behind the shared Open Brush scene.

Open Brush keeps the passthrough environment consistent for everyone in the room and prevents accidental environment changes that would take a participant out of passthrough. Multiplayer rooms can also now support up to 12 people.

## Windows Explorer Sketch Thumbnails on Steam

The Windows Explorer thumbnail extension is now included with the Windows Steam release. A new button in Open Brush opens the installer location, making it easier to enable preview thumbnails for `.tilt` files without downloading the extension separately.

Once installed, the extension shows each sketch's saved thumbnail while you browse your files in Windows Explorer. Read more about [organizing your saved sketches](../user-guide/saving-and-sharing-your-open-brush-sketches.md#organizing-your-sketches).
