# Folder Navigation

The Folder Navigation UI allows you to organize and browse imported images, videos, 3D models, background images and saved strokes in a hierarchical folder structure within Open Brush.

## What does it do?

Instead of displaying all your media files in a single flat list, the folder navigation system allows you to:

1. Browse media files organized in folders and subfolders.
2. Navigate through directory hierarchies without leaving Open Brush.
3. Keep large media libraries separated into useful categories.

## Where to find it

The folder navigation UI is part of the [Media Library](using-the-open-brush-tools-quick-tools-and-menu-panels/extras-panel/media-library.md) panel, accessible from:

1. Open the **Extras Panel** (click and hold the bottom icon on your palette)
2. Select **Media Library**
3. Choose **Local Images**, **Local Models**, **Local Videos**, **Background Images** or **Saved Strokes**.

## How to organize your media

Your media files are stored in:

1. **Images:** `Documents/Open Brush/Media Library/Images/`
2. **Videos:** `Documents/Open Brush/Media Library/Videos/`
3. **Models:** `Documents/Open Brush/Media Library/Models/`
4. **Background images:** `Documents/Open Brush/Media Library/BackgroundImages/`
5. **Saved strokes:** `Documents/Open Brush/Media Library/Saved Strokes/`

You can create subfolders within these directories to organize your content. For example:

```
Documents/Open Brush/Media Library/Models/
├── Architecture/
│   ├── Buildings/
│   └── Furniture/
├── Nature/
│   ├── Trees/
│   └── Plants/
└── Characters/
```

## Using the folder navigator

When browsing the Media Library:

1. Select the current path button to open a list of its subfolders, then select a folder to enter it.
2. Select **Up** to return to the parent folder.
3. Select **Home** to return directly to that media type's root folder.
4. Use the page arrows to browse additional files in the current folder.
5. Select a file thumbnail to load or place the item.

## Tips

1. Keep folder names short so they remain readable on the path and folder buttons.
2. Use groupings that match how you look for media while working.
3. Move or rename files outside Open Brush if you want to reorganize the library.
